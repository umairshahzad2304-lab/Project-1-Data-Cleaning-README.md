# DecodeLabs Internship – Project 1: Data Cleaning & Preparation

## Overview

This project was completed as part of the DecodeLabs Data Analytics Internship Program.

The objective was to clean and prepare a raw dataset by identifying missing values, validating records, checking duplicates, and ensuring data consistency.

## Project Objectives

- Identify missing values
- Remove duplicate records
- Validate date formats
- Verify transaction data
- Prepare data for analysis

## Data Cleaning Tasks Performed

### Missing Values
- Found missing values in CouponCode column
- Replaced missing values with "No Coupon"

### Duplicate Records
- Checked duplicate rows
- Checked duplicate Order IDs
- No duplicates found

### Date Validation
- Verified date formatting consistency
- Standardized date format

### Data Validation
- Verified TotalPrice = Quantity × UnitPrice
